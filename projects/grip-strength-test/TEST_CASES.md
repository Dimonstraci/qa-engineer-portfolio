# Тест-кейсы: Grip Strength Test

Демонстрационный стенд: лабораторное WPF-ПО Grip Strength Test для оценки силы хвата мышей. Клиент получает числовые показания силы через физический Arduino или виртуальную пару COM-портов, строит график «сила - время» и экспортирует измерения в CSV. Ручной набор содержит **30 тест-кейсов в 6 сценариях**.

## 1. Обнаружение и подключение к порту

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Список портов | Открыть приложение | Доступные COM-порты отображены; при наличии выбран первый. |
| TC-02 | Подключение на 9600 | Выбрать доступный порт и `9600`, нажать «Подключить» | В логе есть подключение; кнопки меняют состояние. |
| TC-03 | Подключение на 115200 | Повторить TC-02 на `115200` | Установлено подключение с выбранной скоростью. |
| TC-04 | Порт не выбран | Очистить выбор порта, нажать «Подключить» | Показано предупреждение, подключение не создано. |
| TC-05 | Недоступный порт | Выбрать отключённый/занятый порт, нажать «Подключить» | Ошибка записана в лог; приложение остаётся работоспособным. |

## 2. Приём и валидация данных

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-06 | Целое значение | Передать `42` | Значение есть в логе и на графике. |
| TC-07 | Дробное значение | Передать `12.5` | На графике отображается `12.50`. |
| TC-08 | Отрицательное значение | Передать `-3.25` | Значение принято без ошибки. |
| TC-09 | Экспоненциальная форма | Передать `1e3` | Значение интерпретировано как `1000`. |
| TC-10 | Пробелы | Передать ` 12.5 ` | Пробелы игнорируются, принято `12.5`. |
| TC-11 | Буквенная строка | Передать `abc` | Строка проигнорирована; приложение не завершается. |
| TC-12 | Запятая как разделитель | Передать `12,5` | Строка не принята, поскольку протокол использует инвариантную точку. |
| TC-13 | Пустая строка | Передать пустую строку | Нет новой точки и сбоя. |
| TC-14 | Некорректный формат | Передать `12.3.4` | Нет новой точки и сбоя. |

## 3. История и график

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-15 | Последовательность значений | Передать 10 возрастающих чисел | На графике 10 точек в корректном порядке. |
| TC-16 | Временная ось | Передать два значения с паузой | X-координата второй точки больше первой. |
| TC-17 | Лимит истории | Передать 501 корректное значение | Остаются последние 500 измерений. |
| TC-18 | История после переподключения | Получить данные, отключиться и подключиться снова | Предыдущие точки очищены перед новым сеансом. |
| TC-19 | Высокая частота | Передавать данные не реже 10 строк/с в течение минуты | Интерфейс остаётся отзывчивым, приём продолжается. |

## 4. Экспорт CSV

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-20 | Быстрое сохранение | Получить данные, нажать «Сохранить» | Создан CSV с именем по шаблону `grip_strength_data_*.csv`. |
| TC-21 | Заголовок CSV | Открыть экспортированный файл | Первая строка — `Timestamp,Value`. |
| TC-22 | Формат значения | Экспортировать `12.5` и `-3.25` | Значения имеют две цифры после точки: `12.50`, `-3.25`. |
| TC-23 | Сохранение как | Нажать «Сохранить как…», выбрать путь | Файл создан по выбранному пути. |
| TC-24 | Отмена сохранения как | Открыть диалог и отменить | Файл не создан, ошибка не показана. |
| TC-25 | Пустая история | Не получать данные, нажать «Сохранить» | CSV содержит только заголовок. |

## 5. Отключение и завершение

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-26 | Отключение во время приёма | Нажать «Отключить» | Приём остановлен, порт освобождён, кнопки возвращены в исходное состояние. |
| TC-27 | Повторное подключение | Выполнить отключение и новое подключение | Новый сеанс запускается без перезапуска приложения. |
| TC-28 | Закрытие окна | Закрыть приложение во время приёма | Приложение закрывается без исключения, порт освобождён. |

## 6. Устойчивость к ошибкам стенда

| ID | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-29 | Таймаут чтения | Не передавать данные более секунды | Приложение продолжает ожидать данные без ошибки в логе. |
| TC-30 | Разрыв соединения | Физически отключить Arduino/виртуальный порт во время приёма | Ошибка чтения зафиксирована, приложение корректно отключается. |

Автотесты в `Grib_V2.0test.Tests` покрывают разбор входных значений, потокобезопасную ограниченную историю и CSV-экспорт. Аппаратные сценарии выполняются вручную с Arduino или виртуальной парой COM-портов.
