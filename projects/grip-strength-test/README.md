# Grip Strength Test

Демонстрационный стенд для лабораторного ПО, оценивающего силу хвата мышей. WPF-приложение получает показания устройства по COM-порту, строит график «сила - время» и сохраняет результаты в CSV.

## QA-артефакты

- [30 ручных тест-кейсов в 6 сценариях](TEST_CASES.md): подключение, валидация данных, график, CSV, отключение и устойчивость к ошибкам стенда.
- 24 xUnit-автотеста: разбор входящих чисел, потокобезопасная ограниченная история и CSV-экспорт.

## Запуск

Требования: .NET 8 SDK и Windows.

```powershell
dotnet test Grib_V2.0test.sln --configuration Release
dotnet run --project Grib_V2.0test.csproj
```

Аппаратные проверки выполняются с Arduino или виртуальной парой COM-портов. Протокол ожидает числовые значения с десятичной точкой, например `12.5`.
