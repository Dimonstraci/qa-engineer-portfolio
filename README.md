# QA Engineer Portfolio

Одностраничное портфолио QA-инженера с акцентом на системный анализ, тест-дизайн и работу с рисками.

## Внутри

- featured case: Slotly — аналитическая спецификация системы онлайн-записи;
- подход: декомпозиция требований, моделирование процессов, risk-based testing;
- ссылки на OpenAPI, SQL, ADR и 26 приёмочных сценариев;
- адаптивная верстка без сборщика и внешних зависимостей.

## Запуск

Откройте `index.html` в браузере. Сайт также опубликован через GitHub Pages.

Основные материалы кейса: [appointment-system-analysis](https://github.com/Dimonstraci/appointment-system-analysis).
